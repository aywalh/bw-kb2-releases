# BW-KB2

Windows app for the BlitzWolf BW-KB2 keyboard: lighting, per-key colours, key remapping and macros.

**[Download the latest version](https://github.com/aywalh/bw-kb2-releases/releases/latest)**, run `BW-KB2-Setup-….exe`, done. The app updates itself.

Windows may warn about an unknown publisher because the installer has no paid code-signing certificate.
